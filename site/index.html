Punch Card Machine

Type a short program, or punch the keys below. Each line is one card. The machine runs exactly what the cards say.

READY. Feed a deck, then run it.
Instruction card

PRINT words prints words. ADD number number prints their sum. BEEP rings. REPEAT count BEEP rings count times. Blank cards are ignored. Anything else is a jam, shown with its card number.
